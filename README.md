## 🎓 AI Voice Agent for Education

A complete guide on building and deploying an AI-powered voice agent tailored for educational purposes. The project uses **Next.js**, **React**, **Tailwind CSS**, and leverages speech-to-text, LLM, and text-to-speech services to manage real-time conversation flows.

Learn how to:
- Capture and process voice input  
- Generate responses via LLM
- Rich front-end using React and Tailwind   
- Deploy to a production environment
